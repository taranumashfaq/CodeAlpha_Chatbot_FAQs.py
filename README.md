# Chatbot For FAQ's Python
- A simple chatbot build by using python that answers frequently asked questions using the keyword matching.

## Features
- Keyword based question matching
- User friendly input
- Simple command line interface
- Easy to costomize with your own FAQs

## How To Run
- Make sure Python 3 is installed
- Download or clone this repository
- Run the following command.

       python chatbot_for_FAQs.py
